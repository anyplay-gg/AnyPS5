# Where the AnyPlay fork differs from upstream

This fork ([anyplaynet/AnyPS5](https://github.com/anyplaynet/AnyPS5)) is [boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5) plus the network bridge and the CI around it. Everything is generic: no row below exists for one title. Anything not listed here is upstream's, and a sync takes it as it is.

The table is checked, not trusted. `python3 tools/fork_divergence.py` compares the fork to upstream (`upstream/main`, fetched first) and fails when a file differs from upstream without a row here, or when a row matches no differing file. The [sync workflow](../../.github/workflows/sync-upstream.yml) runs it on every sync branch. Add a row in the same pull request that adds a new place of divergence, and delete the row when the divergence goes away (for example when a fix is accepted upstream).

A path ending in `/` is a directory, any other path may use `*`. Each pattern is in backticks in the first column.
